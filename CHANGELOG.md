# Release notes

This log records repository-level releases. It does not claim changes to the upstream Takamori Robot HIRO library.

## v1.1 — documentation and UI maintenance

- Reorganized the movement reference into smaller, grouped GIF galleries.
- Added a short documentation map and focused cross-links between related guides.
- Removed the obsolete Part 1 status sentence from the web-app footer.
- Preserved firmware behavior, the serial protocol, movement catalog, canonical GIF files, and platform identity.

## v1.0 — Part 1 complete

- Added the documented Arduino movement tester, browser-based Web Serial control interface, terminal, mock transport, movement catalog, tests, and setup guidance.
- Established the initial project structure and safety/compatibility documentation.

## Versioning approach

Version numbers describe this playground repository only. Hardware validation and upstream HIRO library releases are tracked separately and must not be inferred from this log.
